overlay.angle_radius

Авто-подбор радиуса дуги для узких углов: scale = (pivot_rad / angle) ** exp, затем clamp в [min_px, max_arm_fraction × arm_length × ptUnit].

КлючТипDefaultЭффект
enabledboolfalseopt-in; меняет визуал всех углов
expfloat0.25показатель; 0 = без скейлинга
pivot_radfloatπ/2угол, при котором scale = 1.0
min_pxfloat12нижний порог радиуса, px
max_arm_fractionfloat0.65верхний порог как доля от длины короткой стороны
apply_to_rightboolfalseприменять ли clamps к метке прямого угла

Per-element escape: elem.style['auto_radius'] = False — фиксирует arc_size_px для конкретного угла, даже если глобальный флаг включён.

AnimaGeoScene — публичное API

Загрузка

loadGGB(filepath, style_file=None, px_size=None, import_policy=None, debug=False, generate_stubs=True, strict=False, reference_size=None, export_size=None, export_fit='contain', export_source_rect='ggb_view', export_scale=None, export_anchor='center', export_offset=None, export_bounds_padding=0, export_infinite_policy='ignore')загрузить .ggb; px_size — legacy размер холста, reference_size/export_size разделяют эталонный стиль-холст и физический export-холст; export_source_rect: ggb_view или rendered_bounds

putCode(code, debug=False, show=True)исполнить строку DSL (exec-движок; циклы, def, kwargs, .field access)
applyStyle(style_file=None, px_size=None, import_policy=None, reference_size=None, export_size=None, export_fit='contain', export_source_rect='ggb_view', export_scale=None, export_anchor='center', export_offset=None, export_bounds_padding=0, export_infinite_policy='ignore')применить style.json и настроить viewport/export-layout; если export_size не передан в split-режиме, px_size используется только как fallback physical size; rendered_bounds измеряет видимые mobject-ы до финального fit
reloadPolicy(import_policy)пересобрать с другой политикой без повторного парсинга

animageo-board/v1 — board spec

Декларативный, eval-free контракт между Python (exportJSXGraph(output="spec")) и фреймворк-агностичным JS-рантаймом. JSON-схема: animageo/exporters/jsxgraph/board.schema.json (поставляется в wheel, доступна через animageo.exporters.jsxgraph.load_schema()).

КлючСмысл
formatвсегда "animageo-board/v1"
boundingbox[left, top, right, bottom] в math-units
size[width, height] контейнера в px
chromeоси/сетка/фон/keep-aspect (импорт из GGB-вида)
inputs[]интерактивные входы: {name, kind, value/x/y, min/max/step, on, t}; kind ∈ point/number/angle/boolean/glider
elements[]элементы в топопорядке: {name, role, kind, engine, parents[], attrs, tracksDrag}; role ∈ input/live/static
coverage[]отчёт live-vs-static по каждому элементу

Структурированные формы parents[]: {"ref": name} · число · [x, y] · [[xs],[ys]] (sampled polyline) · {"fn": body} (живая функция-координата) · {"js": expr} (escape-hatch).
