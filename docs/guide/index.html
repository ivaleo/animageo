AnimaGeo Guide

Полное руководство по AnimaGeo — библиотеке, которая превращает геометрические конструкции (Python-DSL или .ggb) в высококачественные SVG и MP4-анимации. Каждый пример в этом гайде интерактивный: нажмите Edit — отредактируйте код — нажмите Run, и иллюстрация перерисуется через локальный Python-процесс.

Интерактив требует запущенного render-сервера на 127.0.0.1:8765: 
cd /path/to/animageo
PYTHONPATH=. python3.13 docs/guide/server/serve.py
Без сервера гайд всё равно читается — иллюстрации показываются как статические SVG.

Попробовать прямо сейчас

python-DSL · попробуйте поменять координаты 
A = Point(-4.5, -2)
B = Point(4.5, -2)
C = Point(-0.5, 2.8)
p, a, b, c = Polygon(A, B, C)
alpha = Angle(B, A, C)
beta  = Angle(C, B, A)
gamma = Angle(A, C, B)

style(A, B, C, label_visible=True)
alpha.style.label_text = r'$\alpha$'
beta.style.label_text = r'$\beta$'
gamma.style.label_text = r'$\gamma$'

Что такое интерактивный пример

У каждого блока с кодом есть кнопка Edit. Нажав её, вы переключаете блок в режим редактирования: появляется textarea с текущим кодом и панель из трёх кнопок.

КнопкаЧто делает
Run (или ⌘/Ctrl+Enter)Посылает текущий код на локальный render-сервер, получает SVG, обновляет иллюстрацию рядом.
ResetВозвращает исходный код примера (иллюстрация не сбрасывается).
CloseЗакрывает редактор, возвращает исходный SVG.

Только один редактор активен за раз — клик по другому примеру автоматически закрывает предыдущий. Кнопка Скачать всегда отдаёт полный оригинальный .py-скрипт, не фрагмент из редактора.

Локальное исполнение Python. Эндпоинт /render выполняет произвольный Python-код через AnimaGeoScene.putCode(). Сервер слушает только 127.0.0.1 и не должен выходить в сеть.
